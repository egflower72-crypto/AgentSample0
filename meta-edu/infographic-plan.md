## 1. WHY — 배경/문제 (상단 25%)
**헤드라인: "광고비는 썼는데, 왜 손님은 안 올까?"**

- 비주얼: 사장님이 빈 가게 앞에서 광고비 지갑을 열고 고민하는 컷. 머리 위 물음표 3개
- 말풍선 3개 (소스 문제 유형에서 가져온 고민)
  - "목표를 뭘로 골라야 하지?" → 캠페인 목표 선택
  - "예산은 하루에 얼마가 맞지?" → 일일 예산·입찰
  - "누구에게 보여줘야 하지?" → 타게팅
- 핵심 한 줄(강조 박스): **"광고 첫 단추는 '내 목표 정하기'입니다"**
  - 근거: 소스 문항 "광고 집행 전 가장 먼저 고려할 요소 = 명확한 마케팅 목표 설정"
- 보조 도식: 시험 비중 도넛 차트(400제 표지 수치 그대로)
  - Meta 기술의 가치 8% / 비즈니스 존재감 15% / 광고 기초 21% / **광고 생성·관리 46%** / 리포팅 10%
  - 디자이너 메모: 46%는 가장 크게, 형광펜 칠 + "여기가 절반!" 낙서

## 2. WHO/WHAT — 주체/정의 (중단 35%)
**헤드라인: "내 가게 손님은 Meta 어디에 모여 있을까?"**

### 2-1. Meta 앱 가족도 (원형 배치, 중앙에 "Meta")
| 앱 | 한 줄 정의 | 사장님 예시 아이콘 |
|---|---|---|
| Facebook | 그룹·Marketplace로 동네 손님과 연결 | 🏘️ |
| Instagram | 사진·영상으로 새 브랜드를 발견 (릴스·스토리·탐색) | 📸 |
| Messenger | 1:1 실시간 문의 응대 | 💬 |
| WhatsApp | 메뉴·가격 카탈로그 공유 (소규모는 Business 앱) | 🧾 |
| Threads | 텍스트 중심 대화 | 🧵 |
| Audience Network | 외부 제휴 앱에도 광고 노출 | 🌐 |
- 한 줄 메모: **"캠페인 하나로 여러 앱에 동시 노출 가능"** (소스 문항 근거)

### 2-2. 캠페인 목표 5종 (카드 5장, 가게 상황으로 설명)
| 목표 | 질문 형태 | 가게 예시 (소스 문항 기반) |
|---|---|---|
| 인지도 | "우리 가게를 처음 알리려면?" | 새 빵집 개업 소식 |
| 트래픽 | "사이트·매장 방문을 늘리려면?" | 쇼핑몰 오픈, 매장 길찾기 |
| 참여 | "반응(좋아요·댓글)을 늘리려면?" | 이벤트 게시물 |
| 잠재 고객 | "문의·연락처를 모으려면?" | 상담 신청 |
| 판매 | "구매를 늘리려면?" | 연말 온라인 구매 |
- 디자이너 메모: 5장을 계단 모양으로 배치(알리기 → 방문 → 반응 → 문의 → 구매), 사장님이 계단을 오르는 컷

## 3. HOW — 해결책/작동원리 (하단 35%)
**헤드라인: "광고는 어떻게 만들고, 잘 됐는지 어떻게 알까?"**

### 3-1. 5단계 로드맵 (손으로 그린 길 + 이정표)
1. **목표 정하기** — 위 5종 중 선택
2. **구조 잡기** — 캠페인(목표) → 광고 세트(타겟·예산·노출 위치) → 광고(소재) 3층 도식
3. **예산 넣기** — 일일 예산은 '매일 같은 금액'이 아니라 **평균값**(소스 해설)
   - 경고 표시(주황): 계정 지출 한도로 과다 지출 방지
4. **타겟 고르기** — 관심사 / 유사 타겟(기존 고객을 닮은 사람) / 리타게팅(이미 관심 보인 사람)
   - 데이터 연결: 픽셀·전환 API는 이벤트 관리자에서 연결
5. **결과 보기** — 올바른 성과 지표 고르기
   - 사람 수는 '도달', 같은 사람 반복 포함은 '노출' (소스 문항)
   - 데이터 보관 기간: 광고 관리자 최대 37개월 (소스 문항)

### 3-2. 노출 위치 한 컷
- "어드밴티지+ 노출 위치 = 시스템이 성과 좋은 곳에 예산 배분" 말풍선

### 3-3. 하단 주의 박스 (주황 테두리) — 소상공인 필수
- ⚠️ 성과를 100% 보장하는 광고는 없음 (소스 문항)
- ⚠️ 과장 광고 금지 / 개인정보 입력 주의 (광고 정책 영역 7)
